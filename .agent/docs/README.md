# .agent/docs 사용 가이드

이 디렉토리는 **AI 에이전트(Antigravity)가 참고해야 할 프로젝트 문서**를 저장하는 공간입니다.
복잡한 기능을 구현하거나, 특정 규칙을 준수해야 할 때 요구사항을 이곳에 정리해두면 에이전트가 이를 읽고 작업에 반영합니다.

## 📂 어떤 파일을 넣나요?

*   **기획서/요구사항 정의서**: 예: `coupon-requirements.md` (쿠폰 기능 요구사항)
*   **API 명세서**: 예: `external-api-spec.md` (외부 연동 API 명세)
*   **DB 스키마 설계**: 예: `schema-design.md`
*   **비즈니스 규칙**: 예: `point-policy.md` (포인트 적립/사용 정책)

## 🚀 사용 방법

1.  이 폴더(`docs/`) 안에 Markdown 파일(`.md`)을 생성합니다.
2.  요구사항이나 명세를 자유롭게 작성합니다. (불렛 포인트나 표를 사용하면 더 좋습니다.)
3.  에이전트에게 작업을 시킬 때 다음과 같이 말합니다.
    > "docs 폴더에 있는 쿠폰 요구사항(`coupon-requirements.md`)을 참고해서 설계해줘."

## 📝 파일 작성 예시

**파일명:** `coupon-requirements.md`

```markdown
# 쿠폰 기능 요구사항

## 1. 쿠폰 발행
- 관리자는 관리자 페이지에서 쿠폰을 생성할 수 있어야 한다.
- 쿠폰 타입: 정액 할인(Amount), 정률 할인(Percentage)

## 2. 유효성 검사
- 만료일이 지난 쿠폰은 사용할 수 없다.
- 최소 주문 금액을 충족해야 한다.
```

이렇게 정리해두면 에이전트가 훨씬 더 정확하고 일관성 있게 코드를 작성해드릴 수 있습니다.
